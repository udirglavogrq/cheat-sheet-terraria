## Overview

Cheat Sheet is an essential Terraria modding and testing tool that provides a drag-and-drop item spawner, a buff browser for instantly applying any status effect, a morph tool for becoming any NPC, and a god-mode toggle — making it indispensable for mod developers testing content and players who want creative-mode access to any item.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cheat Sheet** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Item Spawner** | Browse and spawn any Terraria item including modded items by name |
| **Buff Browser** | Instantly apply any status buff or debuff to the player character |
| **NPC Morph** | Transform into any NPC or enemy for testing and exploration purposes |
| **God Mode** | Toggle invincibility, infinite mana, and infinite ammo from the menu |
